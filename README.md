# Vale & The Labyrinth

A text-based roguelike dungeon crawler about delving into the Labyrinth beneath Vale in search of fortune—and surviving long enough to bring it back out.

The game emphasizes exploration, resource management, uncertainty, and knowing when to retreat. Combat is intentionally simple; the dungeon itself is the primary challenge.

## Status

**v0.01 — Initial prototype**

The current goal is to build the core playable loop:

**Vale → Labyrinth → Explore → Fight / Loot / Survive → Return to Vale → Improve → Delve Again**

## Design

`DESIGN.md` is the authoritative design specification for the game.

When implementation and documentation disagree, `DESIGN.md` should be treated as the intended behavior unless explicitly stated otherwise.

## Development

The initial version is intended to be a simple text-based game. Architecture, interface, and additional systems should remain subordinate to getting the core gameplay loop working and playtesting it.
